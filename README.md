## 📊 Dashboard Sections

### 💳 Overview Cards

Displays cryptocurrency card information including:

- BTC
- ETH
- EUR
- Card balance
- Card holder information
- Expiry date
- CVV

### 📈 Monthly Report

The dashboard displays financial statistics for:

- Income
- Expenses
- Cashback
- Turnover

### ⚡ Fast Payment

Quick payment categories including:

- Training
- Internet
- Gas
- Movies
- Education
- Electricity
- Food

### 📊 Crypto Chart

An interactive line chart built with **Chart.js** showing BTC and ETH values from January to November.

### 💼 Investments

Investment information is displayed for:

- Unilever
- Tesla
- Monster
- McDonald's

Each investment includes date, time, bonds, amount, and percentage change.

### 🍩 Portfolio Allocation

A doughnut chart displays portfolio distribution between:

- BTC — 42%
- ETH — 28%
- EUR — 18%
- Cash — 12%

---

## 🌙 Dark & Light Mode

The dashboard includes a theme switcher that allows users to switch between:

- ☀️ Light Mode
- 🌙 Dark Mode

The selected theme is stored using **LocalStorage**, so the user's preference remains saved after refreshing the page.

---

## 📱 Responsive Design

The dashboard is designed to work across different screen sizes:

- 🖥️ Desktop
- 💻 Laptop
- 📱 Mobile
- 📲 Tablet

The sidebar automatically changes into a mobile-friendly navigation menu on smaller screens.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/shehla-codex/crypto-Admin-dashboard.git
```

### 2. Open the Project

```bash
cd crypto-Admin-Dashboard
```

### 3. Run the Project

Open `index.html` directly in your browser.

For the best development experience, you can also use **Live Server** in Visual Studio Code.
